# 🐱 쏙쏙 (SsokSsok) — 맥 메뉴바 아이콘 정리

**메뉴바엔 상자 속 고양이 하나만.** 잘 안 쓰는 메뉴바 아이콘은 상자에 쏙 넣어 두고, 고양이에 마우스를 올리면 상자가 열려요. 상자에서 누르면 꺼내지 않고 그 자리에서 앱 메뉴가 떠요.

- ⬇️ **다운로드 (애플 공증):** [최신 릴리스](https://github.com/hanseolhui/ssokssok/releases/latest) · `brew install --cask hanseolhui/tap/ssokssok`
- 유니버설 (애플 실리콘 + 인텔) · macOS 13 이상

## 🚀 설치

**방법 1. 다운로드** — [최신 릴리스](https://github.com/hanseolhui/ssokssok/releases/latest)에서 `SsokSsok.zip` 받기 → 압축 풀고 `SsokSsok.app`을 **응용 프로그램** 폴더로 옮긴 뒤 실행

**방법 2. Homebrew**

```bash
brew install --cask hanseolhui/tap/ssokssok
```

**방법 3. 터미널 한 줄**

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/hanseolhui/ssokssok/main/install.sh)"
```

**처음 한 번: 손쉬운 사용 권한 허용**
시스템 설정 → 개인정보 보호 및 보안 → **손쉬운 사용** → SsokSsok 켜기

## 🐱 할 수 있는 것

### 어느 macOS 에서나

| 하는 법 | 되는 것 |
|---|---|
| 고양이에 마우스 올리기 | 상자가 열려요 (클릭하면 열린 채로 고정) |
| 상자 속 아이콘 클릭 | 꺼내지 않고 그 자리에서 앱 메뉴가 떠요 |
| 상자 속 아이콘 두 손가락 클릭 | 원래 모양으로 열기 · 메뉴바에 꺼내두기 · 앱 종료 · ⭐ 자주 쓰는 메뉴로 고정 |
| **⌃⌥Space** | 어디서든 상자를 열고 앱 이름 · **메뉴 항목**까지 찾기 · Enter 로 바로 실행 (메뉴는 한 번 열어 본 앱부터) |
| ⭐ 고정한 메뉴 (Pro) | 상자 위쪽 버튼 · **⌃⌥1~9** 로 바로 실행 |
| 상자 속 아이콘에 마우스 올리기 | 앱 이름과 앱이 메뉴바에 띄우던 글자(일정 등)가 떠요 |
| 📝 상자 아래 메모 칸 | 바로 적기 · 색 점으로 메모 바꾸기 (무료 1개 · Pro 7개) · ⌃⌥M 이나 고양이 ⌥클릭으로 크게 · 설정 → 상자에서 끄기 |

### macOS 26 이하 — 쏙쏙이 직접 숨겨요

| 하는 법 | 되는 것 |
|---|---|
| 메뉴바 아이콘을 ⌘ 누른 채 고양이에게 | 상자에 쏙 |
| 상자 속 아이콘을 메뉴바로 끌어 올리기 | 메뉴바로 꺼내기 |
| 설정 → 앱 | 앱마다 **메뉴바 / 상자** 정하기 · 새로 생긴 아이콘은 자동으로 상자에 |
| 설정 → 상자 → 화면 | 외장 모니터에선 모두 보이기 · 노치에 가리기 전에 상자로 |

### macOS 27 — 숨기기는 macOS 가, 꺼내 쓰기는 쏙쏙이

| 하는 법 | 되는 것 |
|---|---|
| 시스템 설정 → 메뉴 막대에서 앱 끄기 | 메뉴바에서 빠지고 고양이 상자에 모여요 |
| 메뉴바 아이콘을 ⌘ 누른 채 고양이에게 | 어떤 앱을 끄면 되는지 알려 주고 설정을 열어 줘요 |
| 상자 속 아이콘 → 메뉴바에 꺼내두기 | 설정에서 다시 켜는 방법을 알려 줘요 |
| 자리가 모자라 macOS 가 « 에 접은 아이콘 | 이것도 상자에 모여요 |

**고양이가 알려줘요** — 상자에 넣어 둔 앱에 알림이 오거나 Dock 숫자 배지가 생기면, 고양이가 그 앱 아이콘을 물고 나오거나 메뉴바로 꺼내 줘요 (설정 → 알림에서 고르기). 앱 이름만 확인하고, 알림 내용은 읽어 두거나 저장하지 않아요.

**상자에 보이는 모양** — 앱 아이콘(기본) 또는 **메뉴바 모양 그대로** (macOS 26 이하, 글자 · 일정 · 숫자까지 실제 메뉴바처럼, 화면 녹화 권한 필요)

**상자 순서** — 설정에서 내 순서(상자 안에서 끌어서 바꾸기) · 많이 쓴 순

**언어** — 한국어 · English · 日本語 · 中文 (시스템 언어를 따르고, 설정에서 바꾸기)

**기본은 손쉬운 사용 권한 하나로** — 화면 녹화 권한은 '메뉴바 모양 그대로'를 고를 때만 물어봐요.

## ⭐ 쏙쏙 Pro

Pro 는 **₩4,900** ($4.99) 한 번 결제예요.

- **메모 7개** — 색 점마다 메모 하나씩
- **자주 쓰는 메뉴 고정** — 상자에서 고른 메뉴 항목을 상자 위쪽 버튼과 ⌃⌥1~9 로 바로 실행
- **상황별 보이기** (macOS 26 이하) — 배터리가 낮을 때 · 전원 어댑터를 뺐을 때 · 특정 앱을 쓰는 동안만 그 아이콘을 메뉴바에 꺼내 두기
- **프로필** (macOS 26 이하) — 지금 배치를 이름 붙여 저장하고, 고양이 두 손가락 클릭 → 프로필에서 한 번에 바꾸기
- **고양이 옷장** — 토끼 · 곰 · 리본 · 모자
- **설정 파일** — 내보내기/가져오기로 다른 맥에 그대로

코드는 설정 → ⭐ Pro 에 입력해요 (`SOK-XXXX-XXXX-XXXX`).

## 🍎 macOS 27

macOS 27 부터는 메뉴바 아이콘 숨기기를 macOS 가 해요. 쏙쏙은 숨은 아이콘을 모아 여는 상자가 돼요.

1. **시스템 설정 → 메뉴 막대**를 열고 (쏙쏙 설정 → 상자의 버튼으로도 열려요)
2. 아래 앱 목록에서 숨길 앱을 끄면
3. 그 앱은 고양이 상자에 모여요. 누르면 꺼내지 않고 그 자리에서 메뉴가 떠요.

- 아이콘을 ⌘ 누른 채 고양이에게 놓으면 어떤 앱을 끄면 되는지 알려 드려요.
- 자리가 모자라 macOS 가 « 안에 접은 아이콘도 상자에 모여요. 화면 녹화 권한이 있으면 더 빠짐없이 찾아요.
- 메뉴 막대 설정에서 끄면 아이콘이 아예 사라지는 앱(예: Raycast)은 상자에서도 열 수 없어요.
- macOS 26 이하에서는 지금처럼 쏙쏙이 직접 숨기고, ⌘로 넣고 빼요.

## 알아 두기

- (macOS 26 이하) 맥북 노치 옆처럼 메뉴바 자리가 부족하면 macOS 가 넘치는 아이콘을 숨겨요. 이렇게 macOS 가 숨긴 아이콘은 쏙쏙도 다룰 수 없어요. 자주 안 쓰는 앱을 상자에 넣어 두면 덜 생겨요.
- Bartender · Ice · MenuBox 같은 다른 메뉴바 정리 앱과 같이 켜 두면 아이콘이 엉켜요. 쏙쏙을 켤 때 알려 드려요.

## 🗑 삭제

고양이 두 손가락 클릭 → **쏙쏙 종료** 후 응용 프로그램 폴더에서 `SsokSsok.app` 삭제 (Homebrew: `brew uninstall --cask ssokssok`). 종료하면 숨겨 두었던 아이콘은 모두 메뉴바로 돌아와요.
